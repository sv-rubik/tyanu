# Тяну

Личный торрент-клиент без рекламы для Android и Windows.

| Платформа | Версия | Исходники | Готовая сборка |
| --- | --- | --- | --- |
| Android 9+ · ARM64 | 0.1.3 | [android/](android/) | `Tyanu-0.1.3-arm64.apk` |
| Windows 10/11 · x64 | 0.1.0 | [windows/](windows/) | `Tyanu-0.1.0-Windows-x64.zip` |

Готовые сборки размещаются в разделе **Releases**. Android APK устанавливается поверх предыдущей версии; Windows ZIP нужно распаковать целиком и открыть `Tyanu.exe`. Java для Windows включена в архив.

## Возможности

Magnet-ссылки и `.torrent`, выбор файлов, прогресс и скорости, пауза и продолжение, фильтры, поиск, ограничения скорости, сохранение задач между запусками.

В Android 0.1.3 удаление предлагает три варианта: строка и исходный `.torrent` (по умолчанию), только строка или всё вместе со скачанным содержимым. Для старых задач может потребоваться выбор исходного `.torrent`. Уведомление о фоне снимается при пустом списке или общей паузе; счётчик на иконке отключён.

Windows 0.1.0 поддерживает трей и перетаскивание `.torrent` в окно. Последние изменения удаления и уведомлений Android в эту версию Windows не переносились.

## Сборка

Сборки готовятся локально. GitHub Actions не используются.

- [Android: установка, сборка и ограничения](android/README.md).
- [Windows: установка, сборка и ограничения](windows/README.md).

Зависимости закреплены по версиям и загружаются скриптами `tools/fetch.py`. В репозитории нет скачанных SDK, JRE, библиотек и промежуточных сборок.

Для Android нужен существующий постоянный ключ подписи, который хранится отдельно от репозитория. Перед сборкой укажи `TYANU_KEYSTORE` и `TYANU_KEYSTORE_PASSWORD_FILE` либо положи ключ и файл пароля локально в игнорируемую папку `android/signing/`. Скрипт не создаёт новый ключ автоматически.

## Проверки

- 27 проверок удаления с настоящим native libtorrent: сохранность файлов, удаление `.torrent`, полное удаление, ошибки доступа и повторные попытки.
- 13 проверок переходов фоновой службы.
- Проверки восстановления, паузы, выбора файлов и хэшей.
- Передача локальной раздачи между двумя пирами, включая magnet и выборочное скачивание.
- Графический интерфейс Windows-приложения запускался на Linux.

Запуск EXE на Windows и последний Android-диалог удаления на физическом Samsung не проверены. Журналы и точные ограничения находятся в `verification/` и README соответствующей платформы.

## Зависимости

libtorrent4j 2.1.0-39; FlatLaf 3.8 и Packr 4.0.0 для desktop. Лицензии upstream-компонентов сохранены в `NOTICE.txt` и `licenses/` для каждой платформы. Windows runtime содержит собственные уведомления в `jre/legal/`.
