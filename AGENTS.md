# Работа с проектом

- Android находится в `android/`, desktop — в `windows/`; версии платформ различаются.
- Сборки выполняются локально. Готовые APK и Windows ZIP размещаются в Releases.
- Существующий Android-ключ подписи и пароль хранятся отдельно. Не добавлять ключи или резервные архивы с ключом в Git и не заменять постоянный ключ новым.
- Зависимости загружаются закреплёнными скриптами `tools/fetch.py`; SDK/JRE, JAR и промежуточные сборки игнорируются.
- В Android исходный `.torrent` и скачанное содержимое — разные объекты удаления. По умолчанию удаляются строка и исходный `.torrent`, содержимое сохраняется.
- Сохранять защиту посторонних файлов, проверку infohash исходника и три варианта удаления.
- При изменении логики удаления проверять `TorrentRemovalTest`; при изменении фонового режима — `DownloadLifecycleTest`.
