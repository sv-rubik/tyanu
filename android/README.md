# Тяну 0.1.3

Личный торрент-клиент для Android-планшета.

## Изменения 0.1.3

При удалении предлагаются три варианта:

1. Строка и исходный файл `.torrent` — выбран по умолчанию. Скачанное содержимое остаётся.
2. Только строка — исходный `.torrent` и содержимое остаются.
3. Всё: строка, исходный `.torrent` и скачанное содержимое.

Исходный `.torrent` теперь запоминается как отдельный URI с разрешением Android на доступ после перезапуска. При необходимости пользователь может выбрать его заново. Перед удалением проверяется infohash: файл другой раздачи не удаляется. Для старых задач, добавленных файлом, исходный `.torrent` нужно выбрать: его расположение раньше не сохранялось. После выбора снова показывается подтверждение удаления. Для magnet-задачи, у которой исходного `.torrent` нет, первый вариант удаляет только строку.

Полное удаление использует native `delete_files`, удаляет только файлы раздачи и её part-file. Непустая папка с посторонними файлами сохраняется. Пути за пределами папки раздачи и файлы, общие с другой задачей в списке, защищены. Native-подтверждение удаления ожидается до 30 секунд без блокировки потока интерфейса. При ошибке запись остаётся, сообщение сообщает о частичном результате, если содержимое уже удалено, а исходный `.torrent` удалить не удалось.

Проверены 27 сценариев удаления на Linux с настоящим native libtorrent и изолированными файлами, включая сохранность данных в первых двух вариантах, полное удаление, ошибки доступа, повторную попытку и восстановление ссылок после перезапуска. Android-интерфейс и SAF-провайдеры на физическом Samsung ещё не проверены.

## Изменения 0.1.2

Служебное уведомление удаляется, когда список пуст, все торренты на ручной паузе или больше нет выполняемых задач. Периодическое обновление состояния не публикует его заново. Служба снимается с foreground и освобождает started-состояние; открытый экран может удерживать binding, а после закрытия экрана служба завершает native-сессию и сохраняет состояние.

Добавление/продолжение загрузки включает foreground до выполнения команды. Активная загрузка, раздача и ожидание Wi-Fi для неприостановленной задачи сохраняют уведомление и возможность продолжения в фоне. «Пауза всем» в шторке теперь приводит к удалению уведомления. На иконке счётчик по-прежнему отключён.

Старая native-сессия завершает запись состояния до создания новой при быстром повторном открытии приложения.

Проверены переходы жизненного цикла, сборка APK, версия и тот же сертификат подписи. Полный жизненный цикл Android и Samsung на физическом устройстве пока не проверен.

## Изменения 0.1.1

Исправлен счётчик на иконке: постоянное служебное уведомление больше не должно показываться как «1». Для обновления с 0.1.0 создаётся канал уведомлений без значка и удаляется старый канал. Скорость и кнопка паузы остаются в шторке Android. Отдельного центра уведомлений внутри приложения нет. После установки обновления приложение нужно открыть.

Проверена сборка APK и совпадение сертификата подписи с 0.1.0. Поведение значка на физическом Samsung ещё требует проверки.

Пакет: `ru.sveta.tyanu`. Архитектура APK: ARM64. Android 9 и новее.

## Установка

1. Установить `Tyanu-0.1.3-arm64.apk`.
2. Разрешить уведомления, чтобы видеть загрузку и ставить её на паузу из шторки.
3. При первом добавлении торрента разрешить приложению доступ к файлам в системных настройках. Вернуться в приложение и повторно нажать «Добавить» / «Скачать».
4. По умолчанию файлы сохраняются в `Download/Tyanu`, загрузки разрешены только по Wi-Fi. Это можно изменить в настройках.

## Возможности

- Magnet-ссылки и локальные `.torrent`; приём ссылок из браузера и меню «Поделиться».
- Выбор файлов перед загрузкой `.torrent`; для magnet список появляется после получения метаданных и доступен в подробностях.
- Пауза и продолжение каждого торрента, общая пауза, фильтры, поиск.
- Показ скоростей загрузки/отдачи, прогресса, пиров и сидов.
- Фоновая загрузка через foreground service с уведомлением.
- Сохранение задач, паузы, выбора файлов и native resume data между запусками.
- Проверка хэшей локальных файлов.
- Выбор папки во внутренней памяти, на SD-карте или USB, если Android предоставляет обычный путь и разрешает запись. Облачные папки не поддерживаются.
- Ограничение скорости; Wi-Fi по умолчанию.
- Открытие готового файла во внешнем приложении с временным правом чтения.
- Удаление предлагает выбор строки, исходного `.torrent` и скачанного содержимого.
- Нет рекламных SDK, аналитики, аккаунтов и сервера приложения. Торрент-протокол связывается с трекерами и другими пирами по данным добавленного торрента.

После загрузки торрент продолжает раздачу до ручной паузы. «Только Wi-Fi» определяет транспорт активной сети; для VPN без сведений о транспортной сети используется признак тарифицируемости Android. Отдельная привязка сокетов к VPN в этой версии не реализована.

## Ограничения первой версии

- Сборка и подпись APK проверены. Пройден 21 тест состояния с настоящей native-библиотекой: импорт, ошибки входных данных, выбор файлов, нативные флаги паузы, восстановление, хэши существующих файлов, экспорт magnet и сохранность файлов после удаления задачи.
- Интерфейс на Android-устройстве или эмуляторе не запускался. На физическом Samsung нужна проверка установки, разрешений, внешнего накопителя и фоновой загрузки.
- Полный обмен между пирами проверить в сборочной среде не удалось: среда запрещает native-движку открытие сетевых сокетов (`SessionErrorAlert: Operation not permitted`). Успешную загрузку через сеть не подтверждаем.
- Для приложений с targetSdk 35 Android ограничивает работу фонового `dataSync`-сервиса шестью часами. Приложение обрабатывает системное завершение; открытие приложения позволяет запустить сервис снова. Ограничения энергосбережения Samsung также требуют проверки на устройстве.
- Задачи сами не запускаются после перезагрузки планшета: нужно открыть приложение.
- Встроенного проигрывателя, RSS, прокси-настроек и потокового просмотра нет.
- Эта версия не готовилась к публикации в магазинах. Широкий доступ к файлам запрашивается для прямой записи native-движком в пользовательскую папку.

## Сборка

В репозитории находятся исходники, лицензии и скрипты загрузки закреплённых зависимостей. Ключ подписи хранится отдельно.
Python 3 и Java 21 runtime достаточно для основной сборки; первоначальная загрузка Android Build Tools 35, Android API 35 и ECJ требует интернета.

```bash
python3 tools/build.py
```

Результат: `dist/Tyanu-0.1.3-arm64.apk`.
`tools/fetch.py` загружает инструменты Google и зависимости из Maven Central.
Код компилируется ECJ с Android boot classpath; D8 преобразует Java bytecode в DEX; APK подписывается apksigner.

Для обновлений используется существующий ключ. Перед сборкой укажи пути к нему и файлу пароля в `TYANU_KEYSTORE` и `TYANU_KEYSTORE_PASSWORD_FILE` либо положи их локально в игнорируемую папку `signing/`. Без ключа подписанная сборка останавливается; новый ключ автоматически не создаётся.

SHA-256 сертификата подписи:
`0828ca3935d4a09bc1803be5c8b0eca020c14f9ee547bdb8f336e48008a528de`

## Проверки

`tools/CoreStateTest.java` проверяет поведение с реальным Linux native libtorrent без скачивания из интернета.
`tools/EngineIntegrationTest.java` — тест полной передачи между двумя локальными BitTorrent-сессиями; для него требуется среда, разрешающая native-сокеты и loopback-подключения. В текущей среде тест не прошёл из-за запрета открытия native-сокетов.
Запуск этих тестов на Linux x86_64: `python3 tools/test_core.py`.
Результат пройденной проверки: `verification/core-state-tests.txt`.

Используются libtorrent4j 2.1.0-39 (MIT), libtorrent 2.1 (BSD) и связанные upstream-компоненты. Лицензии находятся в `licenses/` и `NOTICE.txt`; эти же уведомления включены в APK.
