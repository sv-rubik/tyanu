# Тяну для Windows · 0.1.0

Личный торрент-клиент для Windows 10/11 x64. Первая тестовая версия.

## Запуск

1. Распаковать весь архив в обычную папку.
2. Запустить `Tyanu.exe`. Не переносить EXE отдельно: рядом должны оставаться библиотеки и папка `jre`.
3. Если системная политика блокирует native launcher, есть альтернативный запуск `Start-Tyanu.cmd`.

Java уже включена в архив, отдельно устанавливать её не нужно.
Установка, права администратора, учётная запись и рекламные сервисы не требуются.
Windows может запросить разрешение брандмауэра для входящих соединений торрент-движка.
Сборка не подписана коммерческим сертификатом Windows; предупреждения системы о неизвестном издателе возможны.

## Что есть

- Magnet-ссылки и файлы `.torrent`, в том числе перетаскивание в окно.
- Выбор файлов перед добавлением `.torrent`; список magnet появляется после получения метаданных.
- Список загрузок, поиск, фильтры, скорости, прогресс, пиры и сиды.
- Пауза / продолжение, проверка хэшей, копирование magnet.
- Открытие папки и готовых файлов.
- Выбор папки для новых загрузок, ограничение скорости загрузки и отдачи.
- Восстановление задач, паузы и выбора файлов после перезапуска.
- Работа в трее, если трей поддерживается системой. При закрытии окна можно выбрать продолжение в трее или завершение с сохранением состояния.
- Защита от одновременного запуска двух экземпляров, работающих с одними данными.
- Скачанные файлы сохраняются при удалении торрента из списка.

После завершения загрузки торрент раздаётся до ручной паузы.
Изменение папки в настройках применяется только к новым задачам.

По умолчанию загрузки находятся в `%USERPROFILE%\Downloads\Tyanu`, состояние и настройки — в `%LOCALAPPDATA%\Tyanu`.
Автозапуск и ассоциации `.torrent`/magnet в реестр не добавляются. Передавать файл или ссылку можно через интерфейс, перетаскивание или аргумент запуска `Tyanu.exe`.
Режим ограничения по Wi-Fi в Windows-версии пока не реализован; приложение использует доступное сетевое подключение.

## Приватность

В коде нет рекламы, аналитики и сервера приложения.
Как любой торрент-клиент, движок общается с пирами, DHT и трекерами, указанными в добавленной раздаче. Не заявляется анонимность или специальная защита VPN.

## Проверки и ограничения

Пройдены 21 проверка состояния native-движка и полная передача локальной раздачи между двумя пирами: .torrent с выбором файлов, magnet с получением метаданных, проверка байтов и восстановление после перезапуска. Графический интерфейс запущен и проверен на Linux: добавление раздачи на паузе, выбор файлов, карточка и подробности, завершение и восстановление.
Полные журналы находятся в `verification/` исходного архива.
Windows EXE и DLL проверены по формату и архитектуре, зависимости находятся в комплекте. На реальной Windows эта сборка не запускалась: запуск EXE, поведение брандмауэра, системного трея и пути с кириллицей ещё требуют проверки.

## Исходники и сборка

Репозиторий содержит код приложения, скрипты загрузки закреплённых библиотек, сборки и лицензии.
Основной движок перенесён из Android-версии без изменения формата состояния.

```bash
python3 tools/fetch.py
python3 tools/build.py
```

Требуются Python 3, Java 21 runtime и интернет для первоначального получения инструментов.
Результат: `dist/Tyanu-0.1.0-Windows-x64.zip`.
Packr позволяет упаковать Windows-версию из Linux; при этом Windows-программа не считается проверенной запуском.

Используются libtorrent4j 2.1.0-39, FlatLaf 3.8, Packr 4.0.0 и Azul Zulu OpenJDK JRE 21.0.13.1 для Windows x64. Список источников и SHA-256 загруженных файлов — `tools/dependencies.json`.
Лицензии включены в `NOTICE.txt`, `licenses/` и каталог `jre/legal/` runtime.
